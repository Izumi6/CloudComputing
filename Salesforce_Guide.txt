PART B: CREATE CUSTOM OBJECT (Student__c)
----------------------------------------------------------------
1. Gear icon → Setup → Object Manager → Create → Custom Object
2. Label: Student, Plural: Students, Record Name: Student Name
3. Check: Allow Reports, Allow Activities
4. Save

5. Add Fields (Object Manager → Student → Fields → New):
   - Roll_Number (Number, Length 5)
   - Email (Email)
   - Department (Picklist: CS, IT, ENTC, Mech)
   - CGPA (Number, Length 4, Decimal 2)
   - Phone (Phone)
   - Year (Picklist: FE, SE, TE, BE)

PART K: VIVA QUESTIONS
----------------------------------------------------------------
Q: What is Salesforce?
A: Cloud-based CRM platform with PaaS for custom app development.

Q: What is Apex?
A: Object-oriented language by Salesforce, similar to Java.

Q: What is SOQL?
A: Salesforce Object Query Language, like SQL for Salesforce data.

Q: What is a Custom Object?
A: User-created database table with __c suffix (e.g. Student__c).

Q: What is a Trigger?
A: Code that runs before/after DML events on records.

Q: What are Governor Limits?
A: Runtime limits (100 SOQL queries, 150 DML per transaction).
